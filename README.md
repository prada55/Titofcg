# TITO-FCG — site web

## Déploiement GitHub Pages
1. Téléverse **tout le contenu de ce dossier** dans la branche `main` de ton dépôt GitHub.
2. Vérifie que `index.html` est à la racine du dépôt.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Après le déploiement, GitHub affichera l'adresse du site.

## Formulaire de contact
Le site fonctionne sur GitHub Pages en utilisant WhatsApp comme solution de secours.
Le fichier `api/contact.js` est conservé pour un déploiement Vercel avec les variables `RESEND_API_KEY` et `CONTACT_TO`.

## Important
Ne renomme pas le dossier `img` et conserve les fichiers images à l'intérieur.
